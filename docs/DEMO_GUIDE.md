# TravelMind Agent — 演示指南（Demo Guide）

> 比赛演示用。按此流程可完整展示系统的多 Agent、RAG、多模态三大能力。
> 启动：后端 `cd backend && python -m uvicorn app.main:app --host 0.0.0.0 --port 8000`；
> 前端 `cd frontend && npm run dev`；或双击根目录 `start-dev.bat`。访问 http://localhost:5173

## 演示路径（约 5 分钟）

### 1. 首页 — 系统自检（30 秒）

- 打开 http://localhost:5173
- 点击「🔍 检测后端连接」→ 显示 `API: healthy`（`Database: unavailable` 属正常，数据库为可选组件）
- 讲解点：5 个功能入口、前后端连通性

### 2. 图片识别 — 多模态闭环（90 秒，**核心亮点**）

- 进入「图片识别」，上传一张旅行照片（建议：真实风景/地标照）
- Kimi `kimi-k2.6` 返回：识别地点 + 置信度、地标特征、一句话描述、风格标签
- 自动触发全库跨城搜索（覆盖 30 城市 / 1,721 POI）→ 展示相似景点卡片

### 3. 智能推荐 — 6 因子打分（60 秒）

- 进入「智能推荐」，输入：`想去重庆看夜景，吃火锅`
- 展示 20+ 个推荐景点（李子坝、洪崖洞、长江索道等应位于前列）
- 展开任意卡片的评分明细：偏好匹配 / 热度 / 预算 / 位置效率 / 时间 / 数据可靠性
- 讲解点：Profile Agent 画像提取 → 趋势分析 → RAG → 6 因子加权

### 4. 行程规划 — 完整 Agent 管线（90 秒，含 LLM 生成，需等待）

- 进入「快速体验」或访问 `/itinerary?q=推荐重庆3日游`
- 等待 30-60 秒（DeepSeek 生成中），展示：
  - 行程概述 + 天气卡片（Open-Meteo 实时预报 + 适宜度评分）
  - 3 天时间线：分时段景点、三餐推荐、交通贴士
- 讲解点：LangGraph 7 节点管线，单节点失败不中断（容错设计）

### 5. AI 对话 — SSE 流式（30 秒）

- 进入「AI 对话」，发送：`成都适合带老人去吗？`
- 展示逐字流式输出（SSE）
- 讲解点：旅游领域 system prompt，回答聚焦旅行规划

## 备用示例输入

| 场景 | 输入 |

## 演示前检查清单

- [ ] `backend/.env` 三个 Key 已配置：DEEPSEEK / MOONSHOT / AMAP
- [ ] 后端启动无报错（首次启动会加载 Chroma 向量库，约 5-10 秒）
- [ ] 前端 5173 可访问，首页健康检查通过
- [ ] 提前跑一遍流程 2-4（DeepSeek/Kimi 首次调用较慢，预热后更快）
- [ ] 关闭 VPN/代理（后端已内置绕过系统代理，但关闭更稳妥）

## 常见问题

- **图片识别 502**：检查 `MOONSHOT_API_KEY` 是否为 platform.kimi.com 的开放平台 Key（不是 Kimi Code 会员 Key），且账户有余额
- **行程生成超时**：DeepSeek 偶发慢响应（已有 retry），刷新重试即可
- **端口占用**：Windows 下若 5173 被占，用 `netstat -ano | findstr :5173` 找到 PID 后 `taskkill /PID <pid> /F /T`
